# Chrome 网上应用店上架材料

按 [Chrome Web Store 图片规范](https://developer.chrome.com/docs/webstore/images) 整理。文案可直接粘贴到开发者后台。

本扩展**不是**国家中小学智慧教育平台官方产品。上架时请如实声明，并遵守商店政策与平台服务条款。商店可能审核「下载受版权保护内容」类扩展，请准备好「仅个人学习、不托管不分发、需用户自行登录官方平台」的说明。

## 详细介绍（粘贴到 Store listing）

```
按学段、学科、版本等分类浏览国家中小学智慧教育平台电子教材，批量下载到本地，便于个人学习与教学备课。

主要功能：
• 学段 / 学科 / 版本 / 年级 / 册次筛选
• 批量下载 PDF，按「学段/学科/版本」自动分目录保存，文件名与书名一致
• 在线查看：使用已登录凭据直接打开教材 PDF
• 可选：写入 PDF 目录书签、下载配套音频
• 点击工具栏图标即可打开全页下载界面，不向官网插入广告条

使用前请先在浏览器登录国家中小学智慧教育平台。本扩展会在本地读取登录状态，不会把账号密码发到第三方服务器。

请注意：
• 本工具不是官方应用，与平台没有隶属或合作关系
• 教材版权归原平台及相关权利人所有
• 仅供个人学习与教学参考，禁止商用或二次分发
• 本扩展不存储、不托管、不分发任何教材文件，资源均从官方地址下载到你的电脑
```

## 单一用途说明（隐私问卷 / Single purpose）

```
帮助已登录用户从国家中小学智慧教育平台筛选并下载其有权访问的电子教材（PDF）及可选配套音频，仅用于个人学习与教学参考。
```

## 权限说明（隐私问卷）

**storage**  
在本地保存登录凭据（access token 等）以及「PDF 书签 / 配套音频」选项，方便下次打开继续使用。数据只存在用户浏览器中。

**downloads**  
将教材 PDF、可选音频保存到用户指定的下载目录。

**tabs**  
打开官方登录页、教材在线 PDF，以及点击工具栏图标时打开扩展页面。

**主机权限**

- `basic.smartedu.cn` / `www.smartedu.cn` / `auth.smartedu.cn`：检测登录状态、打开官方页面
- `*.ykt.cbern.com.cn`：读取公开教材目录，下载用户已登录可访问的教材文件

**远程代码**  
不使用。所有逻辑打包在扩展内。

**用户数据**  
不出售、不用于广告、不传给开发者服务器（本扩展没有自有后端）。登录凭据仅保存在 `chrome.storage.local`。
